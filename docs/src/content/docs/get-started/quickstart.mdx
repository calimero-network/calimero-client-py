Every `CloudClient` method is **synchronous**: it blocks (with the GIL released)
until the node answers and returns a plain Python value. There is nothing to
`await`.

## Connect

```python
from calimero_client_py import CloudClient, CloudError, SoftPasskey

# A development cluster serves mock quotes; production nodes are pinned to a
# signed mero-tee release instead (tee_profiles=[...]).
client = CloudClient("http://127.0.0.1:2428", allow_mock=True)
```

The constructor does not contact the node. The first request fetches its
attestation, verifies it against the policy, and opens the sealed channel; a
node that fails the check raises `CloudError` with status `0`.

## Sign in

Scripts and tests against development clusters use an in-memory passkey:

```python
passkey = SoftPasskey()            # rp_id="localhost", origin="http://localhost:3000"
session = client.sign_up(passkey, "alice")
print(client.me()["accountId"])
```

Services use an API key instead:

```python
key_id, key = client.create_api_key({"label": "ci", "ttlSecs": 86400})
service = CloudClient("http://127.0.0.1:2428", allow_mock=True)
service.use_api_key(key)
```

## Deploy and call

```python
wasm = open("kv_store.wasm", "rb").read()
bundle = client.upload_bundle(wasm)
app = client.create_app("kv", bundle)

r = client.call(app, "set", {"key": "a", "value": "1"}, idempotency_key="k1")
print(r["index"], r["result"])

print(client.view(app, "get", {"key": "a"})["result"])

for e in client.events(app, start=0, limit=10, timeout=5):
    print(e["id"], e["kind"], e["data"])
```

## Handle errors

```python
try:
    client.get_app("no-such-app")
except CloudError as e:
    message, status, code, details = e.args
    print(status, code)
```
