`calimero-client-py` is the Python client for Calimero 1.0, backed by a native Rust core, built
with [PyO3](https://pyo3.rs/) and [maturin](https://www.maturin.rs/). Two
importable modules are installed:

- **`calimero_client_py`** — the compiled extension: the classes and functions
  documented in the [API reference](/reference/api/).
- **`calimero`** — a thin Python package that re-exports the same names.

## Requirements

- **Python 3.9 or newer** (CPython).

PyPI carries one prebuilt wheel per platform, built against Python's stable ABI
(`abi3`), so it installs on every CPython from 3.9 on without compiling:

| Platform | Wheel |
| --- | --- |
| Linux x86_64 | `manylinux2014_x86_64` (glibc 2.17+) |
| Linux aarch64 | `manylinux2014_aarch64` (glibc 2.17+) |
| macOS Apple silicon | `macosx_11_0_arm64` |
| macOS Intel | `macosx_10_12_x86_64` |
| Windows x86_64 | `win_amd64` |

:::note[Other platforms build from source]
Anywhere else (musl Linux, 32-bit, PyPy) pip falls back to the source
distribution and compiles the Rust extension, which needs a stable Rust
toolchain and a C compiler on `PATH`. Install Rust with
[rustup](https://rustup.rs/):

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```
:::

## Install from PyPI

<Tabs>
  <TabItem label="pip">

```bash
pip install calimero-client-py
```

  </TabItem>
  <TabItem label="pipx">

```bash
pipx install calimero-client-py
```

  </TabItem>
</Tabs>

A pre-release is installed only when asked for: `pip install --pre
calimero-client-py`, or `pip install calimero-client-py==1.0.0rc1`.

## Verify

```bash
python -c "import calimero_client_py; print(calimero_client_py.VERSION)"
```

That prints the installed version.

## Install from source

Clone the repository and build with maturin. `maturin develop` compiles the
extension and installs it into the active virtual environment in one step.

<Steps>

1. Clone and enter the repository:

   ```bash
   git clone https://github.com/calimero-network/calimero-client-py.git
   cd calimero-client-py
   ```

2. Install maturin and build in development mode:

   ```bash
   pip install maturin
   maturin develop --release
   ```

3. Confirm the import works:

   ```bash
   python -c "import calimero_client_py; print('ok', calimero_client_py.VERSION)"
   ```

</Steps>

:::note
The Rust core depends on `calimero-client` and `calimero-identity` from
`github.com/calimero-network/core` (tag `1.0.0-rc.1`), so the first build
fetches and compiles those too. A network connection is required for the initial build.
:::
