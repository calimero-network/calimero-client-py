---
title: Error handling
description: What the client raises — CloudError for a failed request, ValueError for a malformed argument.
sidebar:
  order: 2
---

- **`CloudError`** — a request failed. Its `args` are
  `(message, status, code, details)`:
  - `status` is the node's HTTP status, or `0` when the node could not be
    reached or attested (`code` is then `"TRANSPORT"`);
  - `code` is the node's error code, for example `CONFIRM_REQUIRED`;
  - `details` is a JSON string (`"null"` when there are none).
- **`ValueError`** — a malformed argument caught before sending (an `app_hash`
  that is not 32 bytes of hex, an unparseable URL, `parent` and `to_top` given
  together) or an answer missing a field the method returns.

```python
import json
from calimero_client_py import CloudError

try:
    client.call(app, "clear")
except CloudError as e:
    message, status, code, details = e.args
    if status == 0:
        print("node unreachable or not attested:", message)
    else:
        print(status, code, json.loads(details))
```
