The client talks to a [Calimero](https://calimero-network.github.io/core/)
release-v2 cluster: each app instance is replicated by its own Raft log across
attested TDX nodes. Attestation, the sealed channel and passkey handling run in
core's Rust `calimero-cloud-client`, so Python applies the same trust check as
every other client.

:::note[The v1 client is gone]
Versions up to 0.9.0 also shipped a client for v1's peer-to-peer node
(`create_connection`, `create_client`, `Client`, `sign_warrant`, ...). Release-v2
deleted that node, and this package deleted its client; see the
[changelog](https://github.com/calimero-network/calimero-client-py/blob/master/CHANGELOG.md)
for what replaces each name.
:::
